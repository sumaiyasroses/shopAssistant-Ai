> An AI-powered customer support chatbot that handles real shopping queries instantly — no wait times, no frustration.

🔗 **Live Demo → [shopAssistant-Ai](https://sumaiyasroses.github.io/shopAssistant-Ai/)**

---

## ✨ What It Does

ShopAssist AI is a conversational support bot built for e-commerce customers. It understands natural language and responds like a real support agent — instantly.

- 📦 **Order Tracking** — Ask about your order, get real-time status updates
- ↩ **Returns & Refunds** — Guided return flow in seconds
- 💳 **Payment Help** — Supports cards, UPI, wallets, and COD queries
- 👤 **Human Escalation** — Seamlessly hands off to a live agent with a ticket number
- ⚡ **Instant Responses** — Powered by Groq's blazing-fast LLaMA 3.1 inference

---
